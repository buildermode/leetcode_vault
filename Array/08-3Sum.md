## Problem
Given an integer array `nums`, return all the triplets [nums[i], nums[j], nums[k]] such that i != j != k != i and the three numbers sum to 0. The solution set must not contain duplicate triplets.

**LeetCode**: https://leetcode.com/problems/3sum/
**Difficulty**: Medium

## Approach
Sort the array, then use a two-pointer approach for each element. Fix one element and find two others that sum to its negation.

## Solution
```python
def threeSum(nums):
    nums.sort()
    result = []
    for i in range(len(nums) - 2):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        if nums[i] > 0:
            break
        left, right = i + 1, len(nums) - 1
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total == 0:
                result.append([nums[i], nums[left], nums[right]])
                while left < right and nums[left] == nums[left + 1]:
                    left += 1
                while left < right and nums[right] == nums[right - 1]:
                    right -= 1
                left += 1
                right -= 1
            elif total < 0:
                left += 1
            else:
                right -= 1
    return result
```

## Complexity
- **Time**: O(n²)
- **Space**: O(1)
