## Sample Questions
This folder contains curated sample questions and variations of the Blind75 problems for additional practice.

### Organization
- **Easy** - Fundamental practice problems
- **Medium** - Standard interview-level problems  
- **Hard** - Advanced challenge problems
- **Mixed** - Problems combining multiple concepts

### Purpose
Use these sample questions to:
1. Test understanding before attempting official problems
2. Practice variations and edge cases
3. Build confidence with easier versions
4. Challenge yourself with harder variants
5. Track progress on similar problem types

### Guidelines
When adding new sample questions:
- Link to the related official Blind75 problem
- Include problem statement
- Add hint (optional)
- Provide solution with complexity analysis
- Tag by difficulty and category
