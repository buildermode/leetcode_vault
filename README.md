# LeetCode Vault

A demo vault for learning LeetCode with Claude Code or Codex.

## Key Takeaway

Optimize the loop between active recall and feedback from your coding agent. Try to solve the problem from memory first, then use the agent to check your reasoning, surface gaps, and tighten the next attempt.

## Getting Started

1. Download and open the desktop app at [thinkingfs.com](https://thinkingfs.com).
2. Open this folder as your vault.
3. Start Claude Code or Codex in the vault and work through problems from there.
