## Practice Sessions & Exercise Attempts
This folder tracks your practice sessions, attempted solutions, and progress on Blind75 problems.

### Session Organization
Sessions are organized by date and contain:
- **Date-based folders**: YYYY-MM-DD format for each study session
- **Problem attempts**: Your solutions and approach notes
- **Time tracking**: Duration spent on each problem
- **Notes**: Key learnings and mistakes
- **Results**: Success/failure and issues encountered

### Session Structure
Each session folder should contain:
```
Sessions/2026-10-22/
├── Array-01-Two-Sum.md (your attempt)
├── Array-02-Best-Time.md
├── Session-Notes.md (summary & learnings)
└── Metrics.md (time spent, success rate)
```

### What to Track
For each problem attempt, record:
- **Approach**: Your initial thought process
- **Implementation**: Your code solution
- **Testing**: Test cases you verified
- **Issues**: Bugs or inefficiencies found
- **Time Spent**: Duration to solve
- **Status**: Completed/Partial/Failed
- **Learnings**: What you learned

### Session Summary Template
Include a `Session-Notes.md` with:
- Problems attempted
- Concepts practiced
- Difficulties encountered
- Topics to review
- Next session goals
